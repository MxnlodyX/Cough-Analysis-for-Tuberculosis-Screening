# Cough Analysis for Tuberculosis Screening

## 📌 Project Overview
This repository contains the source code, experimental notebooks, and data processing pipelines developed for the **Practical Data Science** coursework and ongoing **Research & Development (R&D)**. 

**Research Topic:** 
*Cross-Dataset Generalization of Tuberculosis Screening from Cough Audio to Thai Smartphone-based Clinical Recordings*

## 📖 About The Research
Pulmonary Tuberculosis (PTB) screening through cough audio analysis has shown great potential. However, models trained on standardized datasets often struggle to perform well on real-world data. 

This project aims to evaluate and improve the cross-dataset generalization of deep learning models (such as 2D CNNs). Specifically, we focus on processing short cough audio clips and extracting robust acoustic features (e.g., Spectrograms) to ensure that the models can reliably classify PTB vs. Non-PTB on clinical recordings collected via smartphones in Thailand.

## 🎯 Objectives
- To implement and evaluate machine learning pipelines as part of the Practical Data Science curriculum.
- To investigate the domain shift between public cough audio datasets and Thai smartphone-based recordings.
- To develop robust audio processing and feature extraction techniques (e.g., using the first 0.5 seconds of cough signals).
- To benchmark various deep learning architectural paradigms for this specific audio classification task.
